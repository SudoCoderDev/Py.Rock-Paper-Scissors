# ✊ Rock Paper Scissors Game

A simple **Rock Paper Scissors** game built with Python. Play against the computer, which randomly chooses rock, paper, or scissors. The program compares both choices and announces the result.

## 🎮 How to Play

Choose one of the following options:

- `0` — Rock 🪨
- `1` — Paper 📄
- `2` — Scissors ✂️

The computer randomly selects its choice, and the game determines whether you win, lose, or draw.

## 🛠️ Built With

- **Python 3**
- `random` module for generating the computer's choice
- `input()` for receiving user input
- Conditional statements (`if`, `elif`, `else`) for determining the result

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/rock-paper-scissors-python.git
   ```

2. Navigate to the project directory:

   ```bash
   cd rock-paper-scissors-python
   ```

3. Run the Python program:

   ```bash
   python main.py
   ```

   If your system uses `python3`, run:

   ```bash
   python3 main.py
   ```
